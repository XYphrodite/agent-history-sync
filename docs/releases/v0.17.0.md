## Новое

- `--manage` перенесён с TUI (Spectre.Console) на Desktop (Avalonia), как `--sessions`: тёмное окно `#17191C`, один список с фильтром `All agents / Codex / Grok / Claude / Continue / Kimi`, поиск по заголовку/id (+ FTS), предпросмотр разговора (сообщения и tool-вызовы с пейджингом), поиск внутри сообщения.
- Копирование между агентами и удаление — из того же окна: `Copy` / `Copy to…` (выбор цели когда доступно больше одного агента), `Delete…` с подтверждением. Активные и нечитаемые сессии нельзя копировать/удалять — бейджи `● Active` / `Unreadable` как и в TUI, но в стиле Viewer.
- `--manage` и `--sessions` — отдельные окна (не вкладки), общий `DesktopSessionServices` и `SessionSearchIndex`. Старый `SessionManagerApplication`/`SpectreSessionManagerView` сохранён для тестов, но больше не маршрутизируется для `--manage`.

## Исправлено

- Нет изменений формата синхронизации; `ObjectKind`, индекс и шифрование не менялись.

## Совместимость и ограничения

- Требует Windows для запуска окна; на Linux/macOS доступен только просмотр/поиск (`--sessions`) как и раньше. Для `--manage` нужен установленный агент-получатель (иначе `Copy` отключена).
- Релиз содержит Windows x64 `agent-sync.exe` и контрольную сумму SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
