## Обновление

- Добавлен framework-dependent light вариант (`agent-sync-light.exe`, ~1.5 MiB) рядом с self-contained `agent-sync.exe`. Установщик `scripts/install.ps1` теперь `auto` — при наличии .NET 10 рантайма ставит light, иначе full; `-Variant` форсит выбор, маркер `.agent-sync-variant` фиксирует выбор для `agent-sync update`.
- Сборка релиза публикует оба ассета + `.sha256`.
