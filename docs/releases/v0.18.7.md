## Обновление

- Добавлена иконка Agent Sync: встречные стрелки в цветах интерфейса на тёмном фоне.
- Иконка встроена в Windows EXE и подключена к окнам менеджера и просмотра сессий. ICO содержит 9 размеров от 16 до 256 пикселей для разных масштабов отображения.
- В репозиторий добавлены исходник SVG и скрипт генерации PNG/ICO без сборки приложения.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.
