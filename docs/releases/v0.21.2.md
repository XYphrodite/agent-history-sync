## Новое

- Каждое копирование и удаление сессии пишется в `%LOCALAPPDATA%\CodexHistorySync\logs\session-operations.log`: UTC-время, операция, агент и id сессии с заголовком, назначение, `OK`/`FAIL` и та же безопасная причина, что в статус-баре.
- В журнал попадают и UI-отказы, которые раньше исчезали вместе с окном: `Active sessions cannot be copied.`, `This session cannot be copied.`, `No other agent is available…` и другие.
- Файл — append, best-effort: сбой записи журнала не прерывает copy/delete. Текст переписки, нативные пути и сырые исключения в журнал не попадают.

## Совместимость

- Формат хранилища не менялся. Обновлять все машины перед `push` не требуется.
- Старая сборка просто не пишет `session-operations.log`; остальное поведение прежнее.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
