## Исправлено

- `--manage` показывал панель Kimi пустой: состояние менеджера пересобирало снимок каталога через четырёх-агентный конструктор и теряло список Kimi при открытии экрана, при поиске по `/` и при обновлении по `R`. Панель теперь показывает сессии Kimi, как и поиск/просмотрщик.
- Мелочь: `AgentName` представления менеджера знает явные имена Continue и Kimi вместо fallback на `ToString()`.

## Совместимость и ограничения

- Без изменений относительно v0.16.0. Напоминание: `ObjectKind.KimiSession` — новое число в индексе; все машины репозитория должны быть обновлены до первого `push` с Kimi-сессией.
- Релиз содержит Windows x64 `agent-sync.exe` и контрольную сумму SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```

Подробности: [Kimi Code CLI sessions](https://github.com/XYphrodite/agent-history-sync/blob/v0.16.1/docs/operations.md#kimi-code-cli-sessions).
