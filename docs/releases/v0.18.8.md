## Muse при выключенной WSL

- Добавлено прямое чтение истории Muse из `ext4.vhdx` остановленных дистрибутивов WSL 2. Приложение не запускает Linux и не требует заранее сохранённой копии истории.
- Для чтения нужен установленный 7-Zip в стандартном каталоге `Program Files/7-Zip`. Если он отсутствует или диск недоступен, приложение объясняет причину; истории остальных агентов продолжают отображаться.
- Поддерживаются автоматическое обнаружение диска и явный `MUSE_HOME` с путём `\\wsl$\...` или `\\wsl.localhost\...`. Работающие дистрибутивы по-прежнему читаются через обычную файловую систему.
- Список использует метаданные и заголовки из индекса Muse. Журнал выбранной беседы извлекается во временный файл и удаляется после чтения; весь диск и вся история не распаковываются. Подсессии доступны через просмотр дерева беседы.
- Сессии из образа помечены как доступные только для чтения: удаление и перенос в другого агента отключены. Фоновая полнотекстовая индексация таких сессий пропускается; поиск внутри открытой беседы работает.
- Если состояние WSL изменилось, переоткройте приложение. Изменение диска во время чтения обнаруживается и требует обновления списка.

На проверенном ПК при выключенной WSL отображаются 140 основных сессий и открывается выбранная беседа примерно за 14 секунд. Автоматические проверки включают чтение настоящего тестового VHDX с файловой системой ext4.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.
