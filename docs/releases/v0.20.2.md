## Исправлено

- В `--sessions` и `--manage` список MiMo больше не засорён служебными сессиями.
  - Дочерние потоки внутренних агентов (`checkpoint-writer` и им подобные, `parent_id` задан) скрыты и не синхронизируются — как subagent-потоки Codex.
  - Сессии легаси прошлой генерации MiMo (`version` `2.1.x`) скрыты из списка чатов: текущая MiMoCode их не показывает. Синхронизация этих сессий сохранена, чтобы история не считалась удалённой на других машинах.
- Итог: в фильтре MiMo остаются только чаты текущей MiMoCode и копии, созданные `agent-sync`, вместо сотен записей разных поколений.

## Совместимость

- Без изменений формата.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
