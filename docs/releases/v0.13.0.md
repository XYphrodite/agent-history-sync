## Новое

- Серверное хранилище: зашифрованная история теперь может храниться в PostgreSQL на собственном сервере. Linux API и PostgreSQL запускаются через Docker Compose.
- Подключение через Tailscale без API-токена. Сервер только хранит зашифрованные данные; поиск, SQLite-каталог и MCP работают на клиенте.
- Синхронизация сессий Codex, Grok, Claude Code и Continue, аннотаций и памяти Claude. Поддержаны конфликты, удаления и подключение второго устройства.

## Исправления

- Копирование диалогов в Codex регистрирует новую сессию в его базе через app-server и проверяет видимость всех сообщений, включая ответы ассистента.
- Ошибка регистрации после сохранения больше не создаёт повторные копии.
- Исправлена сборка релиза: проверяется уже опубликованный Windows single-file, а сервер отдельно тестируется на Linux с PostgreSQL.

Существующее GitHub-хранилище не переключается автоматически. Перенос истории выполняется отдельным шагом. Инструкции: [серверное хранилище](https://github.com/XYphrodite/agent-history-sync/blob/v0.13.0/docs/server.md).
