## Новое

- Профиль можно выбрать для одной команды: `agent-sync sync --profile xeon`, `agent-sync --sessions --profile reader`. Флаг работает и перед командой.
- `--select-profile` открывает меню выбора стрелками. Для скриптов и MCP используйте `--profile <name>`.
- Команды `profile list`, `profile add`, `profile show` и `profile remove` управляют именами подключений. Существующие настройки можно зарегистрировать через `--data-dir`, отдельную копию истории — через `--sessions-dir`.
- Выбранный профиль определяет подключение, ключи, состояние синхронизации, каталог SQLite, аннотации, настройки названий и журналы ошибок. Регистрация не переносит историю и не копирует ключи.

## Исправлено

- Синхронизация больше не ждёт бесконечно завершения всех процессов Codex. При открытом Codex локальные изменения его истории откладываются; отправка данных и работа с другими агентами продолжаются.
- Счётчик `deferred-active=N` и пояснение показывают отложенные изменения. Их предыдущее состояние синхронизации сохраняется; изменения повторяются при следующем запуске после закрытия Codex.
- Открытый Codex больше не блокирует применение истории Claude, Grok, Continue и аннотаций своим общим ожиданием.
- Выбор профиля сохраняет правильный поток запуска графического просмотрщика. MCP использует выбранный каталог без лишнего текста в протоколе stdio.

## Совместимость и ограничения

- Пока откладываются **все локальные изменения Codex**, включая новые импорты и отдельные копии истории: обнаружение процесса ещё не различает занятые диалоги. Если Codex запускается уже после планирования, проверки перед записью быстро останавливают операцию с пояснением.
- Без флага используется прежнее подключение. Профиль выбирается только на время команды; автоматического переноса данных из GitHub в серверную БД нет.
- Неизвестное имя профиля завершает команду с ошибкой. Удаление имени сохраняет настройки, ключи и сессии на диске.
- `agent run --profile <name>` поддерживается; установка и удаление фоновой задачи с именованным профилем пока недоступны.
- Релиз содержит Windows x64 `agent-sync.exe` и контрольную сумму SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```

Если подключение к серверу уже настроено в каталоге `agent-sync-xeon` внутри домашней папки, зарегистрируйте его в новом окне PowerShell:

```powershell
agent-sync profile add xeon --data-dir "$env:USERPROFILE\agent-sync-xeon"
agent-sync status --profile xeon
```

Подробнее: [настройка профилей](https://github.com/XYphrodite/agent-history-sync/blob/v0.15.0/docs/profiles.md), [синхронизация при открытом Codex](https://github.com/XYphrodite/agent-history-sync/blob/v0.15.0/docs/operations.md#synchronizing-while-codex-is-open).
