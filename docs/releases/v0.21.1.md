## Новое

- При копировании в Hermes каждый дом — отдельный пункт: `Hermes (Windows)` и `Hermes (WSL)`. Если дистрибутивов WSL несколько, к подписи добавляется имя дистрибутива. Копия пишется в `state.db` профиля `default` выбранного дома.
- Сессия не предлагается обратно в тот дом, где она уже лежит. Копия из одного дома Hermes в другой возможна.
- Если дом один, подпись всё равно называет его: кнопка и сообщение «Copied to Hermes (Windows).» или «Copied to Hermes (WSL).», без молчаливого выбора.

## Совместимость

- Формат хранилища не менялся. Обновлять все машины перед `push` не требуется.
- Старая сборка по-прежнему пишет копию в первый дом (`%LOCALAPPDATA%\hermes`, затем `%USERPROFILE%\.hermes`, затем WSL).

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
