## Новое

- Восьмой агент: **Xiaomi MiMo** (MiMo Code). Синхронизируются сессии из `mimocode.db`: один зашифрованный пакет на сессию (`mi-<ses_...>`) со строкой `session` и её `message`/`part`. `auth.json`, `memory`, логи и WAL не читаются и не отправляются.
- Дом MiMo: `MIMOCODE_HOME/data` (`$MIMOCODE_HOME/data/mimocode.db`), затем `MIMOCODE_DB` (абсолютный или относительный к data), затем `XDG_DATA_HOME/mimocode`, затем `~/.local/share/mimocode` (также `%LOCALAPPDATA%\mimocode` на Windows) и `%USERPROFILE%\.local\share\mimocode`. Канальные БД `mimocode-<channel>.db` (`beta`, `prod` и т.п.) сканируются вместе, дубликаты по одному `ses_...` помечаются как uncertain.
- Локальный `rowid` и пустые колонки в пакет не входят, поэтому один и тот же разговор получает один хеш на разных машинах. `time_created`/`time_updated` нормализуются `ms→s` для окна активности.
- Активная сессия MiMo (процесс `mimo`/`mimocode` и сообщение моложе 30 секунд) откладывается до следующего запуска. Каталог без `mimocode.db` не считается удалением всех сессий.
- `--sessions`, `search` и MCP видят MiMo: панель агента, копирование между агентами (`mimo`/`xiaomi`), просмотр и поиск по тексту реплик.
- `status` печатает `mimo-home=`, `mimo-sessions=` и `mimo-uncertain=`. `doctor` добавляет проверку `mimo-paths`.

## Совместимость и ограничения

- **Обновите все машины, которые делят репозиторий, до первого `push` с сессией MiMo.** `ObjectKind.MimoSession` — новое число в зашифрованном индексе (13, следом за `HermesSession`). Старая сборка отвергнет весь индекс, и `pull` перестанет работать для всех агентов, а не только для MiMo. Обновлённая сборка печатает `mimo-sessions=` в `status`, старая — нет.
- Копия в MiMo записывается в `mimocode.db` (primary, с учётом `MIMOCODE_CHANNEL`/`MIMOCODE_DB`) как сессия `ses_...` с `project_id`/`directory`/`title` и `message`/`part` `data` (`{"role":"user"/"assistant","content":...}` + `{"type":"text","text":...}`). Результаты инструментов и reasoning в переносимую копию не входят.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
