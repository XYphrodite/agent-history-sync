## Исправлено

- Копии разговоров в MiMo (команда копирования в `--manage`) теперь открываются в MiMoCode. Раньше `mimo --session` падал с `TypeError: … info.time.created`, а `mimo session list` не показывал такую сессию.
  - Сообщения пишутся в нативном формате MiMo (`time.created`, `agent`, `parentID`) — текст остаётся в `part`.
  - Для сессии создаётся строка в таблице `project`; раньше подставлялся `project_id`, которого в базе не было.
  - Новая база `mimocode.db` сразу получает полную схему (`project`/`session`/`message`/`part`).

## Совместимость

- Без изменений формата хранилища.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
