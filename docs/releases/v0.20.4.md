## Исправлено

- Копии разговоров в MiMo теперь появляются в `mimo session list`. Раньше сессия создавалась с синтетическим `project_id=prj_*`, а список MiMoCode показывает только проект `global` (или проект текущего каталога). Копия без известного MiMoCode-проекта уходит в `global`.

## Совместимость

- Без изменений формата хранилища.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
