## Исправление запуска просмотрщика

Патч сохраняет возможности версии 0.15.0, включая профили и отложенную синхронизацию при работающем Codex.

- Исправлено падение `agent-sync --sessions` с `Operation failed: InvalidDataException`, если первая выбранная сессия нечитаема. Окно остаётся открытым, показывает ошибку этой сессии и позволяет выбрать другой чат.
- Ошибки данных при выборе сессии, поиске по субагентам и экспорте теперь обрабатываются в окне. Поиск сохраняет результаты читаемых сессий; неудачный экспорт не публикует частичную папку.
- Добавлены регрессионные тесты для нечитаемых сессий, включая запуск окна с настоящим локальным каталогом и дублирующимися JSONL-файлами.

Файлы истории и правила проверки читаемости не изменяются. Этот патч не исправляет и не удаляет сами нечитаемые сессии.

Обновление: закройте `--sessions` и `--manage`, выполните `agent-sync update`, затем снова `agent-sync --sessions`.
