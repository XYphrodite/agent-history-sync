## Исправления и производительность

- **MiMoCode (`mimocode.db`):** устранено многоминутное зависание `agent-sync sync` и `status` на больших базах истории (`scanning agent sessions in parallel...`). Загрузка таблицы `part` переведена с поштучных запросов на каждое сообщение на один запрос на сессию, дочерние сессии субагентов пропускаются без чтения сообщений, пакеты хешируются потоково без буферизации в памяти, а каталог сессий и проверка активности читают только заголовки и метки времени.
- **Выгрузка MiMoCode и Hermes:** исправлено чтение открытого пакета в `SyncEngine` при выгрузке (`push` / `sync`) и записи конфликтов для `MimoSession` и `HermesSession`, а также добавлена отложенная обработка сессий MiMo, Hermes и Antigravity при их изменении на лету между сканированием и шифрованием. Для Hermes число теневых копий `state.db` сокращено с `3 + 3N` до `2` за проход сканера.
- **Google Antigravity:** сканер переведён на двухпроходное потоковое хеширование без выделения крупных `byte[]`-буферов в LOH и читает `conversation_summaries.db` один раз на фазу проверки стабильности вместо повторного открытия на каждую сессию.
- **Параллельное сканирование и активность процессов:** сканеры всех настроенных агентов теперь запускаются параллельно на обеих фазах сканирования; в менеджере сессий исправлено определение активного процесса `mimocode`.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage` (и остановите зависший процесс `agent-sync`, если он ещё запущен), затем выполните:

```powershell
agent-sync update
```
