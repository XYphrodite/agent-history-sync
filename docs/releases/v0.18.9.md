## Копирование Muse при выключенной WSL

- Исправлена недоступная кнопка копирования для сессий Muse, прочитанных напрямую из диска выключенной WSL. Копирование в другого доступного агента не запускает WSL и не изменяет исходный образ.
- В окне копирования Muse можно выбрать агента и существующую папку проекта на Windows. Путь проекта из метаданных сессии подставляется автоматически, если он доступен; пути `/mnt/c/...` преобразуются в Windows-пути.
- При копировании сохраняются сообщения и название беседы.
- Рядом с недоступной кнопкой удаления показано объяснение: диск WSL открыт только для чтения. Для удаления оригинала нужно запустить WSL и удалить сессию через Muse.

Исправление проверено 948 автоматическими тестами в CI, включая копирование из тестового VHDX с проверкой неизменности образа. На реальном ПК проверены загрузка истории и окно копирования при выключенной WSL.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.
