## Новое

- Пятый агент: **Kimi Code CLI**. Синхронизируются сессии из `%USERPROFILE%\.kimi-code\sessions`: один зашифрованный пакет на сессию (`ki-<uuid>`) с `state.json`, всеми `agents/<id>/wire.jsonl` и файлами планов, плюс строка сессии в общем индексе `session_index.jsonl`. Каталог `credentials/`, `logs/`, `notify/`, `tasks/`, `cron/` и `upcoming-goals.json` не читаются и не отправляются.
- Индекс Kimi сливается, а не заменяется: при импорте меняется только строка импортируемой сессии, остальные сохраняются; битый индекс останавливает импорт вместо перезаписи.
- `state.json` нормализуется перед упаковкой: абсолютные `agents.*.homedir` заменяются плейсхолдером и подставляются обратно на целевой машине, поэтому хеш пакета воспроизводится между устройствами и не вызывает вечных повторных отправок.
- Активная сессия Kimi (процесс `kimi`/`kimi-code` + запись за последние 30 секунд) откладывается до следующего запуска, как у Claude.
- `--manage`, `--sessions`, `search` и MCP видят Kimi: панель/фильтр агента, копирование между агентами в обе стороны, просмотр и поиск по тексту диалогов.
- `status` печатает строку `kimi-home= … kimi-sessions= … kimi-uncertain=`, `doctor` добавляет проверку `kimi-paths`. Переменная `KIMI_CODE_HOME` задаёт альтернативный дом, как `CODEX_HOME`/`GROK_HOME`/`CLAUDE_CONFIG_DIR`/`CONTINUE_GLOBAL_DIR`; работает и в профилях (`--sessions-dir` → `kimi\sessions`).

## Исправлено

- Нет пользовательских изменений поведения существующих агентов; форматы Codex, Grok, Claude и Continue не менялись.

## Совместимость и ограничения

- **Обновите все машины, которые делят репозиторий, до первого `push` с Kimi-сессией.** `ObjectKind.KimiSession` — новое число в зашифрованном индексе; старая сборка отвергнет весь индекс, и `pull` перестанет работать для всех агентов, а не только для Kimi. Проверка дешёвая: обновлённая сборка печатает `kimi-sessions=` в `status`, старая — нет.
- Копия **в** Kimi синтезируется как нативная сессия (новый UUID, минимальный `wire.jsonl`, строка индекса), но продолжение такой сессии в Kimi Code CLI не верифицировано — относитесь к таким копиям как к архивным транскриптам. Подробности: [compatibility](https://github.com/XYphrodite/agent-history-sync/blob/v0.16.0/docs/compatibility.md).
- Релиз содержит Windows x64 `agent-sync.exe` и контрольную сумму SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```

Подробности: [Kimi Code CLI sessions](https://github.com/XYphrodite/agent-history-sync/blob/v0.16.0/docs/operations.md#kimi-code-cli-sessions), [профили](https://github.com/XYphrodite/agent-history-sync/blob/v0.16.0/docs/profiles.md).
