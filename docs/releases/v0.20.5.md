## Исправлено

- Копии разговоров в MiMo появляются в списке сессий TUI (`/sessions`). Раньше сессия была в `mimocode.db`, но её не было в `history_fts` — а picker строит список именно по нему, поэтому показывал «Ничего не найдено».
- При записи пакета MiMo теперь индексируются текстовые части в `history_fts` (и пересоздаются при перезаписи сессии).

## Совместимость

- Без изменений формата хранилища.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
