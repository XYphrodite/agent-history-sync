## Исправлено

- В окнах `--sessions` и `--manage` выбор агента **MiMo** показывал пустой список (`0 shown`) при наличии локальных сессий. Подпись в списке агентов (`MiMo`) сравнивалась с именем enum (`Mimo`) без учёта регистра. Фильтр стал регистронезависимым; сессии MiMo снова видны в менеджере и просмотрщике.

## Совместимость

- Без изменений формата.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
