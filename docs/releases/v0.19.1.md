## Новое

- Серая строка над заголовком сессии копирует идентификатор в буфер обмена по одному клику. Это работает в окне разговоров и в менеджере.
- В буфер попадает только id, без имени агента и пометки про диск WSL. Подсказка у строки — «Copy session id». После копирования внизу окна появляется «Session id copied.»
- Строка больше не обрезает длинный идентификатор: текст переносится.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
