## Исправления

- **Конверсия и материализация в Google Antigravity (`→ AGY` и `pull`):**
  - устранено падение `SqliteException (NOT NULL constraint failed)` при записи в реальную базу `conversation_summaries.db` (колонки `parent_conversation_id`, `agent_name`, `status` и сопутствующие поля `NOT NULL`);
  - при конверсии и материализации заполняются нативные метаданные AGY: блоб `raw_summary`, статус `CASCADE_RUN_STATUS_IDLE`, `step_count`, `last_user_input_step_index`, таблицы `trajectory_meta` (`cascade_id`, `source`), `trajectory_metadata_blob`, колонка `steps.metadata` со статусом `StepStatusDone` и нативный лог `.system_generated/logs/transcript.jsonl`, чтобы сконвертированные сессии корректно открывались и продолжались через `agy --conversation <id>`.
- **Конверсия и просмотр из Google Antigravity (`AGY → другие агенты`):**
  - из переносимых реплик ассистента исключены промежуточные блоки внутренних рассуждений (`thinking`) перед вызовами инструментов, когда в диалоге присутствуют финальные ответы модели (с сохранением фолбэка на `thinking`, если вся сессия состоит только из рассуждений).

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
