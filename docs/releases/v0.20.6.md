## Исправлено

- Сессии MiMo больше не роняют TUI-пикер с `TypeError: … tokens.output`. В сообщениях ассистента копии не было поля `tokens`, которое MiMoCode читает при построении списка сессий — picker падал и показывал «Ничего не найдено».
- Копия теперь пишет `tokens` (`output`/`input`/`total`/`cache`), `cost`, `finish`, `mode`, `path` — в том виде, в котором их ждёт MiMoCode.

## Совместимость

- Без изменений формата хранилища.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
