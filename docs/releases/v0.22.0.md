## Новое

- Девятый агент: **Google Antigravity** (AGY). Синхронизируются сессии из `conversation_summaries.db`, пошаговых баз `conversations/<id>.db`, опциональных аннотаций `annotations/<id>.pbtxt` и артефактов/транскриптов `brain/<id>/`: один зашифрованный пакет на сессию (`ag-<uuid>`) в каноническом JSON без локальных `rowid`.
- Дом Antigravity: `ANTIGRAVITY_HOME`, затем `ANTIGRAVITY_CLI_HOME`, затем `ANTIGRAVITY_APP_DATA_DIR`, затем `%USERPROFILE%\.gemini\antigravity-cli` и `%USERPROFILE%\.gemini\antigravity`.
- Активная сессия Antigravity (эксклюзивный лок `presence/<id>.lock`, заблокированный `conversations/<id>.db`/`*.db-wal` или процесс `antigravity`/`antigravity-cli` с недавней записью) откладывается до следующего запуска синхронизации и блокируется от удаления/копирования в менеджере сессий. Отсутствие базы в доме помечается как `uncertain` и не считается удалением всех сессий.
- `--sessions`, `--manage`, `search` и MCP видят Antigravity (`antigravity` / `agy`): панель агента, просмотр реплик и блоков рассуждений, дерево субагентов по `parent_conversation_id` (до 32 уровней с защитой от циклов), полнотекстовый поиск FTS5 и двустороннее копирование между всеми агентами.
- `status` печатает `antigravity-home=`, `antigravity-sessions=` и `antigravity-uncertain=`. `doctor` добавляет проверку `antigravity-paths`.

## Совместимость и ограничения

- **Обновите все машины, которые делят репозиторий, до первого `push` с сессией Antigravity.** `ObjectKind.AntigravitySession` — новое число в зашифрованном индексе (14, следом за `MimoSession`). Старая сборка отвергнет весь индекс, и `pull` перестанет работать для всех агентов, а не только для Antigravity. Обновлённая сборка печатает `antigravity-sessions=` в `status`, старая — нет.
- Копия в Antigravity записывается в `conversations/<id>.db` (protobuf-шаги реплик пользователя и ассистента), `conversation_summaries.db` и `brain/<id>/transcript.jsonl`. Вызовы инструментов и внутренние reasoning-блоки исходного агента в переносимую копию не входят.

## Загрузка

- `agent-sync.exe` — автономная сборка Windows x64.
- `agent-sync-light.exe` — облегчённая сборка Windows x64, требующая .NET 10.
- Для обеих сборок опубликованы контрольные суммы SHA-256.

## Обновление

Закройте окна `--sessions` и `--manage`, затем выполните:

```powershell
agent-sync update
```
